# Tsuki · 荣耀 PPG-AN00 上的手机助手

一个**在手机本机运行**的安卓操作 Agent：用一句中文（或英文）说出目标，助手 **Tsuki（月）** 会读屏、思考，再一步步点按、输入、滑动来完成任务，并实时展示每一步。主要面向 **荣耀 PPG-AN00 / MagicOS 10（Android 16）**，其他 Android 8+ 手机同样可以用。

- 包名：`com.runasakura.phoneagent`（debug 版为 `.debug`）· 许可：Apache-2.0
- 开发分支：`feat/mvp-agent`（不直接改 `main`）· 当前版本：**0.14.0-mvp**

> Tsuki 是助手的形象：银色长发、编发头带、黑色缎带、红瞳、月牙。应用名称统一为「Tsuki」（包名不变，升级安装不丢权限）。

## 功能

| 能力 | 说明 |
|---|---|
| 通用操作 | 任意应用里的点按 / 长按 / 双击 / 输入 / 滑动 / `scroll_find` / 返回 / 桌面 / 通知栏 / 快捷设置 / 分屏 |
| 直达工具 | `launch`、`list_apps`（查已安装应用）、`open_url`、`intent`、剪贴板 `copy/paste`、`key enter` |

| 看图 | `deepseek-flash` 可以直接看截图（需要在设置里允许）；也可以用本机 MNN VL 或云端 VL 作为看图辅助 |
| 模型 | 本机 MNN Chat（OpenAI 兼容）或云端 DeepSeek / OpenAI 兼容；**只用你选的模型**，不会自动切换；可选本机离线语音模型（sherpa-onnx） |
| 安全 | ConfirmPolicy：发送 / 通话 / 支付 / 下单 / 卸载 / 闹钟前必须确认；提示注入防护；急停 |
| 学习 | 应用经验、可复用技能、失败归因、在线换法、从你的回答和纠正中学习；**上岗教授**（口述/示范 → 可复用流程，学习页可管理）（全部在本机） |
| 常驻 | 无障碍掉线自愈（WRITE_SECURE_SETTINGS / Shizuku）、开机/更新自愈、可选保活 |
| 外观 | Tsuki 主题：夜月（默认）/ 樱 / 纯月，切换即时生效、整屏换色；悬浮月亮球；月光动效（系统关闭动画时静止） |

## 架构

```mermaid
flowchart LR
    U[你：一句话目标] --> UI[聊天界面 / 悬浮月亮球]
    UI --> S[AgentForegroundService]
    S --> L[AgentLoop<br/>观察→思考→行动→验证]
    subgraph Eyes[读屏]
      T[无障碍树] --> M[屏幕元素合并]
      O[ML Kit OCR] --> M
      Z[色块/角落图标候选] --> M
      P[截图] -.可选.-> V[看图]
    end
    M --> L
    V --> L
    L <--> R[LlmRouter<br/>用户选择的模型]
    R --- C[(云端 DeepSeek /<br/>OpenAI 兼容)]
    R --- N[(本机 MNN Chat)]
    L --> G{SafetyGate +<br/>ConfirmPolicy}
    G -->|需要确认| CF[确认浮窗]
    G -->|放行| H[手：手势 / 输入 / intent / shell]
    L <--> MEM[(经验记忆<br/>技能 / 教训 / 通用界面规律)]
```

一步的流程：读屏（树 + OCR，必要时截图）→ 生成观察（上一步效果、经验提示、屏幕元素）→ 模型输出一个 JSON 动作 → 安全闸 / 校验 → 执行 → 对比界面变化 → 达成后由验收员确认。系统提示保持不变，方便 DeepSeek 前缀缓存命中。

## 安装与设置（荣耀 PPG-AN00）

1. **安装 APK**：从 [Releases](https://github.com/Runa-Asahi/honor-phone-agent/releases) 下载最新 `*-mvp` 预发布版。
2. **无障碍**：设置 → 辅助功能 → 无障碍 → 本应用 → 开启。**每次更新 APK 后**都要确认它仍然开着（首页「上手清单」会提示）。
3. **悬浮窗**：允许「显示在其他应用上层」（用于悬浮月亮球：进度、急停、确认）。
4. **通知**：允许（后台任务状态）。
5. **电池 / 自启动**：设置 → 电池 → 忽略优化；手机管家 → 应用启动管理 → 本应用改为「手动管理」，打开自启动、关联启动、后台活动；在多任务界面锁定本应用。
6. **Shizuku（可选，推荐）**：
   - 安装 Shizuku → 开发者选项 → **无线调试** → 在 Shizuku 里配对并启动。
   - MagicOS **每次重启后 Shizuku 都会停止**，需要回到 Shizuku 用无线调试重新启动。
   - 本应用 设置 → 特权模式（Shizuku，可选）→ 请求授权 → 打开开关。之后会得到：按键注入、`shell` 工具（危险命令始终需要确认）、`shortcuts` 运行时发现应用深链/直达页面。所有 Shizuku 命令都会带时间和调用方记录在诊断日志里。
7. **无障碍自愈**：Shizuku 就绪时，在 设置 → 后台保活（荣耀/MagicOS）→ 「用 Shizuku 授予自愈权限」点一次，授予 `WRITE_SECURE_SETTINGS`。之后服务被系统关掉时会自动重新开启，即使 Shizuku 没有运行、手机重启后也一样。
   - 也可以用 adb：`adb shell pm grant com.runasakura.phoneagent android.permission.WRITE_SECURE_SETTINGS`
8. 打开应用 → 右上角菜单 → **自检**，全部通过后再下任务。

## 模型配置

设置 → 模型：

| 方式 | 说明 |
|---|---|
| **DeepSeek（推荐）** | Base URL `https://api.deepseek.com`，模型 `deepseek-flash`（快、便宜、可以看图）；需要更强时可以手动选 `deepseek-v4-pro` |
| 思考模式 | 「DeepSeek 思考模式」开关，更准但更慢，默认关 |
| 看图 | 勾选「允许向云端发送截图」后，游戏 / 图标 / 自绘界面会附带截图 |
| 本机 MNN | 安装 MNN Chat 并启动 API（`http://127.0.0.1:8080/v1`），选用 Instruct 小模型（不要用长思考模型）；路由选「仅本机」或「本机优先」 |
| OpenAI 兼容 | 自填 Base URL / 模型 |

- **API Key 只在设置页填写**，保存在 `EncryptedSharedPreferences`（AES-GCM）里；日志和诊断只显示遮罩，不要在聊天里粘贴 Key。
- 模型只用你选的那一个：不会自动升级，也不会切换到 pro。

## 本机模型（内置 MNN，v0.10.0 起，v0.11.0 强化）

- **一键下载**：设置 → 本机模型 →「一键下载推荐模型」，从魔塔社区（ModelScope）匿名拉取 `MNN/Qwen3-VL-2B-Instruct-MNN`（公开仓库，**无需登录/Token**）。CDN `resolve/master` 优先，API 回退；断点续传、逐文件 sha256、可取消；通知栏显示速度与剩余时间。
- **使用已下载的模型**：Android 11+ 的分区存储让应用看不到其他应用放在「下载」里的文件，所以现在按三种方式查找：① 已授权 Shizuku 时，以 shell 身份扫描 `/sdcard/Download`、`/sdcard/Documents`、`/sdcard/Android/data/<MNN Chat>`，以及 MNN Chat「本地模型」目录 `/data/local/tmp/mnn_models`；② 用系统文件夹选择器选一次（授权会被记住，下次自动扫描）；③ 应用自己可读的目录。找到多个时让你选择，复制完成后会校验文件大小再启用。**MNN Chat 在应用内下载的模型存放在它的私有目录，没有 root 时任何应用（包括 Shizuku）都读不到**；这种情况下会提示改用「一键下载」（同样来自魔塔社区的文件），或在 MNN Chat 里把模型导出到可见目录。
- **看图优先级**：只要装了内置视觉模型（VL），看图就**优先用 Tsuki 内置的本机模型**；没有内置视觉模型时，才在开关打开的情况下回退到 MNN Chat 的视觉模型。设置页和任务日志（「看图技能：…」「看图能力：…」）会写明当前实际用的是哪一个。
- 推理：JNI + libMNN（含 OpenCL）。加载时自动探测 **OpenCL → CPU**（荣耀 PPG-AN00 / 骁龙 8 Elite 的 Adreno 通常可用 OpenCL；本构建**未启用 QNN/NPU**）。线程数按 CPU 核数自适应（2–6）；看图辅助短提示 + ≤96 token，不阻塞云端决策。
- 路由「云端为主、本机为辅」（推荐）：云端决策；本机后台并行看图；仅离线时本机接管。
- 限制：约 1.5 GB 下载；常驻内存约 1.5–2 GB；CPU 长提示仍可能数秒到数十秒；APK +约 8.5 MB；仅 arm64。

## 安全与 ConfirmPolicy

- **发送消息、拨打电话、支付 / 转账、下单、卸载、设置闹钟**之前，一定会弹出确认（显示对象和内容），你同意后才执行；拒绝也会被记住。
- 普通 `https` 链接直接打开，不需要确认。
- 支付 / 银行类应用直接拦截，交给你手动操作。验证码 / 登录页默认停下，只有你的目标本身就是「填写这个验证码」时才继续。
- 屏幕上的文字一律当作不可信数据：其中的「指令」会被忽略。输入的文字只能来自你的目标、复制得到的内容，或本次任务在屏幕上读到的信息。
- 急停：长按悬浮月亮球、展开面板点「停止」、通知或首页按钮，随时可以停止。

## 学习与经验记忆

全部只保存在本机。设置 →「学习记录」页面按应用列出所有经验、路线和技能，显示「已验证 N 次 / 待验证」和最近一次被证实的时间；点一条可删除，也可以按应用清除或全部清除。

- **应用经验**：每个应用的教训和事实，按与当前目标的相关性检索；矛盾时用新证据替换旧的。
- **可复用技能**：成功任务中真正让界面变化的步骤会沉淀成技能，自动去掉绕路和失败步骤。下次每一步给出「下一步建议」，仍然由模型判断是否采用。同一目标再次成功，技能的验证次数就增加；失败则降级。
- **通用界面规律**：跨应用适用的经验，比如开屏广告、底部 tab、搜索框。
- **失败归因**：分类为循环、找不到目标、步数耗尽、需要你、你拒绝等，转成下次可用的教训。
- **在线换法**：任务中某个动作失败后，换一种做法成功，会记成「X 不行，Y 可以」。
- **从你的回答学习**：追问的回答和急停 / 拒绝都会成为教训。
- **记忆卫生**：只出现一次的教训 10 天过期，验证过的 30 天过期；数量有上限。
- **AI 整理**：某个应用的经验超过 7 条且有新增时，任务结束后用云端模型合并意思重复的条目（也可以在「学习记录」里手动点「AI 整理」）。合并后的条目保留来源中最高的验证次数，不会凭空增加证据；没有云端模型时不整理。
- **后续验证**：任务成功时，这次提示给模型、且与目标相关的经验验证次数 +1（上限 6）；失败则降级。
- **通用经验检索**：跨应用的通用经验按与当前目标的相似度挑选最相关的 3 条注入（之前这部分写入后没有被读出，已修复）。
- **语义检索（可选，本机）**：设置 → 学习 →「下载语义模型（约 217 MB）」，从魔塔社区下载 `MNN/bge-large-zh-MNN`，用 libMNN 自带的 Embedding 引擎在本机 CPU 上运行，不需要新增运行库。经验向量只计算一次，以 float32 形式保存在本机（每条约 4 KB），之后检索不再推理；任务开始时在后台补算目标和新经验的向量（预算 1.5 秒），给模型拼提示词时只读缓存，不会卡住。排序分数 = 字符相似度 + 0.5 × 语义相似度（按 bge 校准到 0–1）。用真实 bge 向量离线评测（20 个手机目标 × 14 条经验）：top-1 从字符相似度的 13/20 提高到 17/20。「成功后验证」使用更严格的门槛（字面相关，或语义分 ≥ 0.5），避免无关经验刷验证次数。没装模型、关闭开关或非 arm64 设备时，自动回到原来的字符相似度。
- **云端 AI 重排（可选，默认关闭）**：每个任务额外调用一次云端模型（5 秒超时），从最相关的 10 条经验里挑出最多 5 条并排序，作为本次任务的加权。
- 为什么不用 Qwen3-Embedding-0.6B：魔塔上的 MNN 导出（约 378 MB）在 MNN 主机构建上实测排序明显不对（top-1 5/20），bge-large-zh 的 MNN 导出表现正常，所以默认选用后者。DeepSeek 官方 API 没有 embedding 接口。
- 经验只在任务开头注入一次，不在每一步重复发送，对前缀缓存友好。

## 外观（Tsuki）

- 主题（设置 → 外观，切换即时生效，背景、卡片、文字、气泡、按钮、状态栏和粒子都会一起变）：
  - **夜月**（默认）：深海军蓝 → 银雾，银色与绯红点缀，银色光尘上浮，新月。支持跟随系统 / 深色 / 浅色。
  - **樱**：月夜海军蓝 / 银灰为底，地平线带一抹暮色玫瑰，柔和樱粉点缀；花瓣稀疏、缓慢飘落；人物沿用沉静的立绘（不用 Q 版）。支持跟随系统 / 深色 / 浅色。
  - **纯月**：珍珠白与柔和银蓝，满月与星芒闪烁；固定为明亮主题（深浅色选项会置灰）。
- **悬浮月亮球**（任务运行时显示，替代旧的急停胶囊，只有一个悬浮窗）：点按展开面板（当前步骤、暂停 / 继续、打开 Tsuki、停止），6 秒后自动收起；**长按立即急停**；可拖动，松手吸附到最近的屏幕边缘；运行时有进度环、脉动光晕和步数角标，暂停时显示琥珀色圆环；颜色跟随主题。Agent 点击和滑动时它会暂时隐藏并且不接收触摸，所在区域也不参与 OCR，Agent 不会点到它。设置 → 外观里可以关闭（改用简洁胶囊）或调整不透明度（40%–100%）。
- 自适应图标（含单色主题图标）、Android 12 启动页、星空渐变背景、月相加载指示。系统关闭动画时，动效会静止。
- 无障碍：主要按钮的触控区为 48dp、TalkBack 描述、标题标记、对比度 ≥ 4.5:1（有单元测试检查）。
- 原图在 `branding/source/`，可以用 `python3 branding/make_assets.py` 重新生成全部图标和插画。

- 读屏、OCR、经验记忆都在本机。只有你配置了云端模型时，屏幕文字（以及你允许时的截图）才会发给**你选的**服务商。

## 流畅度、内存与存储（v0.12.0）

- **流畅度**：设置页的状态卡在首帧之后才在后台计算；聊天列表只重新挂载变化的部分；星空背景的月亮和光晕缓存成小贴图，每帧不再新建渐变；省电模式下背景动画、月相和悬浮球降到约 12 帧/秒，窗口不可见时停止；正在执行的步骤动画在离开屏幕时停止；OCR 预热延后 1.5 秒；语义索引初始化不再在主线程加载原生库。
- **内存**：本机大模型在 App 可见时空闲 10 分钟后卸载，在后台时空闲 2 分钟后卸载，任务进行中不卸载；语义模型空闲 60 秒后卸载，任务开始时算完向量后如果大模型已加载也会立即卸载，避免两个大模型同时常驻；收到系统内存警告（包括 App 进入后台）时卸载语义模型。定时清理统一在一个低优先级后台线程上运行。
- **存储**：设置 →「存储与清理」显示大模型、语义模型、经验向量、模型加载缓存、中断的下载和临时文件各占多少空间；「一键清理」不会删除已安装的模型或学到的经验。每天自动清理一次临时文件和超过 3 天的中断下载（下载进行中不清理）。重复导入同一个模型时直接选用已有的那份，不再多存一份。
- **检索质量**：语义模型改用 fp32 精度计算（避免 fp16 溢出），加载后先自检；经验文本去掉「（本应用实测）」「（未验证）」等标记后再编码；展示经验时跳过意思重复的条目（MMR 去重）；技能匹配可以识别同义说法，但联系人、数字、引号内容、英文词这几类「槽位」必须完全一致，例如「给妈妈发微信」不会复用「给爸爸发微信」的技能（这条规则同样适用于字面相似的情况）。

## 语音输入、卡住修复与性能（v0.13.0）

- **语音输入**：输入框旁的麦克风，点一下开始、再点一下结束，也可以按住说话、松手结束；识别过程中文字实时填进输入框，接在已输入内容后面。设置里可以打开「说完自动发送」（默认关闭）。识别通道按顺序选用：系统离线识别（Android 13+）→ 系统语音识别服务 → 能处理识别请求的语音助手页面 → 输入法自带的语音键。在没有 Google 服务的荣耀 / MagicOS 上，通常会走最后两种，设置页会显示本机实际使用的通道。运行中的悬浮球也有麦克风，用来口述「下一个任务」，当前任务结束后执行。语音发出的任务和手动输入一样，经过相同的确认策略。
- **OCR 状态**：首页的 OCR 标签原来固定显示「离线中文」，这只是布局里写死的默认文字（只有自检后才会更新），没有实际意义。现在改为显示本机 ML Kit 中文识别的真实状态：待预热 / 就绪 · 最近平均耗时 / 识别失败。
- **卡住修复**：浅 / 深混合思考，卡住时自动转入深思考，强制看图、诊断原因并换一个没试过的策略，有进展后回到浅思考；空白点击、坐标熔断（相邻 40px 格也算同一处）、OCR 错字归一、屏幕方向变化后丢弃旧规划、任务进行中不把 Tsuki 拉到前台；用户可以通过口述或示范教 Tsuki 流程（「教我做…」）。
- **性能**：看图时直接复用本步 OCR 已经截好的那一帧，不再截第二次；截图位图用完立即回收；开启 Shizuku 时直接读取原始像素截图，省去 PNG 编码和解码；模型原始响应只在出错时记录；系统提示词压缩回预算以内。

## 本地语音、OCR 增量与上岗教授（v0.14.0）

- **本地离线语音（sherpa-onnx）**：APK 内置 arm64 识别引擎；设置里一键从魔塔下载约 25 MB 中文流式模型（断点续传、逐文件 sha256）。音频只在手机上处理。输入框和悬浮球在模型就绪后都能直接说话；没有系统识别服务的手机同样可用。任务进行中点悬浮球麦克风也可现场申请录音权限，授权后 FGS 会补上 microphone 类型并立即开听。
- **OCR 自适应截图 + 区域增量识别**：去掉固定 340 ms 预等待，改为「界面安静/帧稳定后再截」；无障碍 API 才受约 1 次/秒限制，Shizuku 原始截图零等待。同一应用连续步骤只重识别像素变化的条带，其余行复用；单元基准约只读全屏像素的 40%。
- **主线程 I/O**：任务历史与加密密钥库在后台预热；首页最近任务芯片与历史弹窗走 IO 线程。
- **上岗教授（对标 Grok Bot 示范学习）**：入口「教我做…」；口述或「开始示范」后悬浮教练条跟随进任意应用，点「记录此步」记下包名 + 无障碍/OCR 可见文字（游戏 tree=0 同样可用）；结束后 LLM 整理成可复用流程（目标模板、前置、步骤骨架、失败提示、{占位符}）；学习记录可查看/编辑/验证/删除/立刻试一次；执行时语义检索优先命中教授流程，下一步目标不在屏幕上则自动深思考。

## 真机核对清单（PPG-AN00）

- 安装后开启无障碍；需要悬浮球/上岗教练条时开启悬浮窗；语音先下模型或授录音权限。
